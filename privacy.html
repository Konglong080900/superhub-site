Privacy Policy

Last updated: 20 October 2026

About SuperHub

SuperHub is a tool built for personal use. It is not available to the public.

What Google data it accesses

SuperHub requests one permission only: https://www.googleapis.com/auth/calendar.events. It uses it to create, read, update and delete events in the user's own Google Calendar, for reminders the user has confirmed. It does not access Gmail, Drive, Contacts or any other Google data.

How data is stored

The sign-in token is stored only on the user's own computer, encrypted with Windows Data Protection (DPAPI). Calendar data is not copied to any other server.

Sharing

No data is sold, shared with, or transferred to any third party. Data is not used for advertising or for training AI models.

Google API Services User Data Policy

SuperHub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections. The local token is then deleted.
